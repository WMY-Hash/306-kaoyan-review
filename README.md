## 二、怎么用

### 方式 A：双击打开（最简单）
直接双击 `index.html`，用 **Chrome / Edge / Firefox** 打开即可（不要用 IDE 内置预览、聊天窗口或在线 HTML 预览器打开，它们通常不执行本地脚本，会显示空白侧栏）。

> 注意：极少数浏览器/隐私模式下对 `file://` 的 `localStorage` 有限制，本系统已做**安全降级**（进度改存内存，刷新会重置，但功能照常可用），不会白屏。若点击完全无反应，页面会直接给出正确打开方式的提示。

### 方式 B：本地服务（最稳，推荐）
在 `kaoyan-review/` 目录下执行：

```bash
python3 -m http.server 8080
```

然后浏览器访问 `http://localhost:8080/`。此方式 `localStorage`、进度持久化、导入导出均最稳定。

### 方式 C：PWA 离线安装（推荐网页端用户）
部署到任意 HTTPS 域名（已部署：<https://wmy-hash.github.io/306-kaoyan-review/>），
浏览器右上角会出现「安装」入口；安装后可独立窗口启动、断网使用。

- `manifest.webmanifest` 声明名称/图标/主题色
- `sw.js` 用 stale-while-revalidate 策略缓存 app shell（首次访问后即可离线）
- `vendor/` 已把 3D 星图依赖本地化，**断网不影响任何功能**

### 方式 D：Electron 桌面软件（Windows）
`electron/` 是独立子工程，提供 `npm start` 开发、`npm run build` 出安装包。
详见 [`electron/README.md`](./electron/README.md)。

```bash
cd electron
npm install                # 首次需要，国内建议先设 npmmirror
npm start                  # 开发：弹窗加载 ../index.html
npm run build              # 出 NSIS 安装包 + portable 绿色版到 ../release/
```

学习成本：会 `npm install / start / run build` 即可，约 0.5 小时上手。

### 日常复习建议
1. 左侧点科目 → 章节 → 考点，浏览正文建立框架。
2. 点右下「🃏 复习此考点卡片」逐张自测；答不出就点「✗ 不认识」。
3. 点顶部「📕 错题本」集中重练薄弱点。
4. 定期点「📤 导出」备份进度（换设备时「📥 导入」恢复）。

## 四、如何扩写考点（手写填充）

> 内容按 306 大纲 + 人卫第 10 版手写，并可通过「乐享 AI 知识库」MCP 接入你的私人笔记自动扩写（见下文）。
> 扩写优先级：内科(33%) → 外科(23%) → 生理(14%) → 生化(12%) → 病理(12%) → 人文(6%)。

### 从乐享 AI 知识库（你的私人笔记）扩写

已接入乐享 MCP（`mcporter` + `preset=meta` 懒加载）。你的知识库「医学知识总结」（185 个文件）可经 MCP 浏览与读取：
- 业务工具通过 `call_tool` 包装器调用，例如 `mcporter call lexiang.call_tool tool_name="space_list_recently_spaces" arguments='{}'`
- 阅读文件：`entry_describe_entry` 取 `target_id`（即 file_id）→ `file_download_file` 取临时下载链接 → 下载（Word/PDF）→ `python-docx` / `pypdf` 解析正文
- 阅读在线文档：`block_fetch_page` / `lexiang_search` / `lexiang_fetch`

> 工作流：浏览知识树 → 定位目标笔记 → 解析正文 → 结构化提取为 `point`（正文 + 卡片）→ 追加进 `kb.js` 对应科目/章节。内分泌系统章节即按此流程生成。

所有考点写在 `data/kb.js`，挂在 `window.KB_DATA.subjects` 下。层级：

```
subjects[]        { id, name, weight, chapters[] }
  chapters[]      { id, name, points[] }
    points[]      { id, title, level, tags[], body, cards[] }
      cards[]     { q, a }
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `subject.id` | string | 英文短标识，如 `physio` |
| `subject.weight` | number | 306 权重（%），用于加权覆盖率 |
| `point.id` | string | **全局唯一**，如 `p_physio_006` |
| `point.level` | enum | `高频` / `中频` / `低频` |
| `point.tags` | string[] | 检索与聚合用，如 `["心血管","血压"]` |
| `point.body` | string | 考点正文，用 `\n` 分段 |
| `card.q` / `card.a` | string | 卡片正面（提问）/ 背面（答案） |
| `point.resources` | object[] | **M3 新增**：资料索引，可选。每条 `{ type: "教材"|"讲义"|"真题"|"论文"|"法规", label: string, ref?: string, url?: string }` |
| `KB_PLAN.weeks` | object[] | **M4 新增**：计划闭环数据，见 `data/plan.js`。`week{ id,label,range,phase,books[],tasks[] }` |
| `week.tasks[]` | object[] | 任务项 `{ id, subject?, chapter?, title, note, points }`；`subject`+`chapter` 非空时任务可「打开章节」跳转到对应考点 |

### 扩写示例（往 `physio` 科目追加一个考点）

找到 `subjects` 中 `id: "physio"` 的 `chapters`，在对应 `points` 数组追加：

```js
{
  id: "p_physio_006",
  title: "血管生理与组织液生成",
  level: "中频",
  tags: ["微循环", "组织液", "有效滤过压"],
  body: `一、微循环\n毛细血管网是物质交换场所，受后微动脉和毛细血管前括约肌（局部代谢产物调节）控制。\n二、组织液生成\n有效滤过压 =（毛细血管血压 + 组织液胶体渗透压）-（血浆胶体渗透压 + 组织液静水压）。动脉端滤出、静脉端回流，淋巴回流补足。\n三、影响因素\n血浆胶体渗透压↓（如低蛋白）→ 组织液生成↑ → 水肿。`,
  cards: [
    { q: "有效滤过压如何计算？哪一端生成组织液、哪一端回流？", a: "有效滤过压 =（毛细血管血压 + 组织液胶体渗透压）-（血浆胶体渗透压 + 组织液静水压）。动脉端为正→滤出生成组织液；静脉端为负→回流。淋巴回流回收剩余。" }
  ]
}
```

> 提示：`body` 用反引号（模板字符串）书写最省心，换行直接回车即可；避免在其中使用反引号或 `${`。

## 知识星图（M6）使用与编辑

点顶部「🌌 星图」进入。这是一张把分散考点连成记忆网络的 3D 图，和「思维导图/目录树」不同——它是**网状**的，一个知识点可以同时连很多个，没有上下级束缚。

**浏览**
- 拖拽旋转、滚轮缩放；节点按 6 科着色（蓝=生理 / 绿=生化 / 红=病理 / 橙=内科 / 黄=外科 / 紫=人文）。
- 点击节点 → 右侧弹出详情（正文 + 标签 + 连线）；若节点带「查看考点」按钮，点它直接跳回 M1 对应考点。
- 顶部搜索框在星图内实时高亮命中节点并飞向第一个命中。

**自己编辑（核心）**——无需改代码、无需重部署：
- `＋ 节点`：填名称 / 选科目 / 标签 / 正文，可选填「回链考点 id」（如 `p_internal_001`）即可和 M1 打通。
- `＋ 连线`：选两个节点 + 关系类型（病因 / 机制 / 先修 …）+ 说明，建立一条边。
- 点节点详情里的 `✎ 编辑` / `🗑 删除` 维护内容；连线右侧的 `✕` 删除连线。
- 所有编辑存浏览器 `localStorage`（key=`kg_user`），**不影响种子库 `data/graph.js`**，刷新不丢。
- `⬇ 导出` / `⬆ 导入`：把你的编辑备份成 JSON，换设备或迁移时用。

> 想批量预置？直接编辑 `data/graph.js` 的 `window.KB_GRAPH`（节点 `{ id,name,group,tags,body,refs }`、边 `{ source,target,type,label }`），重新部署即可，与页内编辑互不冲突。

## AI 辅导员（M7）使用与架构

点顶部「🤖 AI 辅导」打开侧边聊天面板。后端用 **FastAPI + ChromaDB + DeepSeek** 做向量 RAG：你的问题 → 从 149 个考点中语义检索最相关的 → 拼成 prompt 发给 DeepSeek → 流式逐字返回。

### 启动后端

```bash
pip install -r server/requirements.txt    # 首次：安装依赖（含本地 embedding 模型）
cp server/.env.example server/.env        # 首次：填入你的 DeepSeek API key
python server/main.py                     # 启动（默认 http://localhost:8765）
```

### 功能

- **自由提问**：输入任何医学问题，AI 自动从考点库检索相关知识作答（流式逐字输出）。
- **考点讲解**：在考点详情面板点「🤖 AI 讲解」，基于该考点全文让 AI 详细讲解（概念/机制/临床联系/记忆技巧）。
- **设置面板**：面板右上角齿轮图标 → 可配后端地址、LLM 提供商、API key。配置仅存本机 `localStorage`。
- **完全离线**：embedding 用本地 `sentence-transformers/all-MiniLM-L6-v2`，无需联网。仅 LLM 调用需网络。

### 切换 LLM

| 提供商 | 配置 | embedding |
|---|---|---|
| **DeepSeek**（当前） | `LLM_PROVIDER=deepseek` + key | 本地模型（零费用） |
| **Gemini**（备用） | `LLM_PROVIDER=gemini` + key | `text-embedding-004`（免费额度） |

换 Gemini 只需改 `.env` 里的两行配置，后端代码零修改。

### 架构

```
浏览器(前端)  ──fetch──▶  FastAPI(本机:8765)  ──DeepSeek API──▶  LLM
                              │
                         ChromaDB(本地向量库)
                              │
                    sentence-transformers(本地 embedding)
```
